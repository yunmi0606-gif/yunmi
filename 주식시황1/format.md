# 노션 저장 포맷 (2026-08-09 ~ 08-13 기존 기록에서 역추적)

> 원본 format.md/claude.md가 이 저장소에는 없어, 노션 "주식시황" 데이터베이스에
> 이미 저장된 지난 기록들의 실제 구조를 보고 재구성한 문서입니다. 원본과 다를 수
> 있으니 확인 후 수정해 주세요.

## 페이지 단위
- 노션 "주식시황" 데이터베이스(각 페이지 제목: `YY.MM.DD`, 예: `26.08.13`)에
  하루 분량의 영상을 모아 한 페이지로 저장.
- 영상 1개당 아래 섹션을 만들고, 영상 사이는 `---` 로 구분.

## 영상 1개 섹션 구조
```
## <영상 제목>
- **링크**: <영상 URL>
- **출연자 이름**: <출연자/게스트>
- **업로드일**: YYYY-MM-DD
- **채널**: <채널 URL>

### 핵심요약
- **이 영상의 핵심 5문장**: ...
- **전체 내용의 정보성 핵심 내용 정리**: ...
- **언급된 종목과 해당 종목에 대한 자세한 내용**: ...
- **결론 또는 참여자가 알아야할 것과 대응방향**: ...

## 한 줄 인사이트
<한 문장 요약>
```

## 비고
- 각 요약은 실제 영상 자막/스크립트를 근거로 작성되어야 함 (추측/창작 금지).
- 이번 실행 환경에서는 유튜브 봇 차단(HTTP 429 / "Sign in to confirm you're not
  a bot")으로 인해 개별 영상의 자막·상세 메타데이터 수집이 실패했습니다.
  collect.py 의 `data/*.json` 출력을 참고해 실패 원인을 확인하세요.
