# 복사해서 쓰는 자동응답 · 홍보 문구

`[대괄호]` 부분만 내 정보로 바꿔서 카카오톡 채널 관리자센터 > 채팅 > 자동응답에 붙여넣으세요.
채팅방 메뉴 버튼의 "보낼 메시지"는 아래 **키워드와 글자 하나까지 똑같이** 입력해야 자동응답이 작동합니다.

---

## 1) 채팅 시작 인사말

```
안녕하세요, [채널명]입니다 🙏
사주명리로 지금의 흐름과 앞으로의 방향을 함께 읽어드립니다.

아래 '채널 메뉴'를 눌러
① 후기 ② 이벤트 복비 ③ 필독 사항 ④ 신청양식 및 계좌
순서대로 확인해 주세요.
```

## 2) 키워드: `소중한 내담자들의 후기`
동의어: `후기`, `리뷰`

```
💌 소중한 내담자분들이 남겨주신 후기입니다.

"[후기 한 줄 예시 1]"
"[후기 한 줄 예시 2]"
"[후기 한 줄 예시 3]"

더 많은 후기 👉 [인스타 하이라이트/블로그 링크]
```
(카드 이미지: 후기 캡처 3~5장 모자이크 처리 후 첨부)

## 3) 키워드: `이벤트 복비 안내`
동의어: `복비`, `가격`, `얼마`, `비용`, `이벤트`

```
🧧 [N]월 한정 이벤트 복채 안내
하루 [3]명만 이벤트 복채로 예약됩니다.

• 1인 종합사주: [50,000]원(X) → [35,000]원(O)
• 2인 종합사주: [100,000]원(X) → [60,000]원(O)
• 2인 궁합사주: [100,000]원(X) → [50,000]원(O)
• 재회+궁합사주: [160,000]원(X) → [80,000]원(O)
• 재회사주: [100,000]원(X) → [50,000]원(O)
• 작명, 출산 택일은 문의 부탁드립니다.

신청은 메뉴의 '신청양식 및 계좌'를 눌러주세요.
```
⚠ 정가(X)는 실제로 그 가격에 판매한 적이 있어야 합니다. 한정 인원도 실제 운영 기준으로 적어주세요.

## 4) 키워드: `필독 사항`
동의어: `필독`, `주의사항`, `환불`

```
❗ 상담 전 꼭 읽어주세요

1. 상담은 입금 확인 순서대로 진행되며, 결과는 [24~48시간] 내 카톡으로 전달됩니다.
2. 정확한 풀이를 위해 출생시간을 확인해 주세요. 모르시면 '모름'으로 적어주시면 됩니다.
3. 사주는 흐름과 경향을 읽는 것이며, 결과를 보장하거나 단정하지 않습니다.
4. 환불: 결과 작성 시작 전 100% 환불 / 결과 전달 후에는 환불이 어렵습니다.
5. 보내주신 개인정보는 상담 목적으로만 사용하며, 상담 종료 [30일] 후 삭제합니다.
6. 추가 질문은 결과 전달 후 [1회] 무료로 답변드립니다.
```

## 5) 키워드: `신청양식 및 계좌`
동의어: `신청`, `양식`, `계좌`, `입금`, `예약`

```
입금계좌: [은행] [계좌번호] [예금주 일부가림 예: 홍*동]

[양식]
• 생년월일 (양력/음력):
• 출생시간 (모르면 '모름'이라고 적어주세요):
• 성별:
• 성함 (또는 상대방 이름):
• 상담 유형: 종합 / 궁합 / 재회 중 택1
• 궁금한 점 혹은 고민:

양식 작성 + 입금 후 '입금완료'라고 남겨주세요 🙏
(궁합·재회는 상대방 정보도 함께 적어주세요)
```

## 6) 키워드: `입금완료`
동의어: `입금했어요`, `입금 완료`, `보냈어요`

```
감사합니다 🙏 입금 확인 후 순서대로 풀이를 시작합니다.
결과는 [24~48시간] 내 이 채팅방으로 보내드릴게요.
양식에 빠진 부분이 있으면 먼저 여쭤보겠습니다.
```

## 7) 상담 시간 외 자동응답

```
지금은 상담 시간이 아니에요 🌙 (상담 시간: [매일 10:00~22:00])
'신청양식 및 계좌'를 작성해 두시면 가장 먼저 확인해 드릴게요.
```

## 8) 결과 전달 후 (직접 보내는 문구)

```
[성함]님, 풀이 결과 보내드렸습니다.
천천히 읽어보시고 궁금한 점은 1회 무료로 답변드려요.

도움이 되셨다면 짧은 후기 남겨주세요 💌
후기 남겨주신 분께는 다음 상담 [10%] 할인을 드립니다.
```

4. 직업·적성

7. 지금 고민에 대한 답: [고객이 적은 고민에 직접 답변]
8. 조언 한마디 & 행운 포인트 (색·방향·시기)
```

```

### 릴스/게시물 마지막 문구 (CTA)
- "내 사주가 궁금하다면 프로필 링크 → 카톡으로 바로 신청"
- "댓글에 '사주' 남기면 이번 달 이벤트 복채 보내드려요" (DM 자동화 툴 연동 시)
- "헤어진 그 사람, 다시 올까? 재회사주 이번 달 반값 👉 프로필 링크"

- 후기 캡처 공유 (모자이크)
