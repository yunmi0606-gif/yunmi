# 사주 상담 카카오톡 채널 수익화 가이드

참고 사례: 인스타그램 `@is_saju` → 카카오톡 채널 "사주정원"

## 0. 먼저 알아둘 것: 스크린샷은 "오픈채팅"이 아니라 "카카오톡 채널"입니다

스크린샷에 보이는 기능은 전부 **카카오톡 채널(구 플러스친구)** 기능입니다.

| 화면에 보이는 것 | 실제 기능 이름 |
|---|---|
| 이름 옆 파란 체크 ✔ | 비즈니스 인증 채널 (사업자등록증 필요) |
| "보통 2시간 내 응답 · 응답률 76%" | 1:1 채팅 켜두면 자동 표시 |
| 노란 버튼 "채널 메뉴 ^" (후기 / 이벤트 복비 / 필독 / 신청양식) | 채팅방 메뉴 |
| 버튼 누르면 이미지+글 카드가 바로 나옴 | 키워드 자동응답 (챗봇) |
| "안녕하세요. 무엇을 도와드릴까요? – 이전 페이지: instagram" | 채팅 시작 인사말 + 유입 경로 표시 |

오픈채팅방으로도 상담은 가능하지만, 수익화용으로는 **카카오톡 채널을 추천**합니다.

| | 오픈채팅 (1:1방) | 카카오톡 채널 |
|---|---|---|
| 개설 난이도 | 1분 | 10분 (인증은 며칠) |
| 사업자 필요 | 없음 | 개설은 없어도 됨, 파란 체크는 필요 |
| 메뉴 버튼/자동응답 | ❌ | ✅ |
| 고객 목록 관리, 단체 메시지 | ❌ | ✅ (친구에게 메시지 발송, 유료) |
| 신뢰도 | 낮음 (익명 프로필) | 높음 |
| 운영정책 리스크 | 영리 홍보 목적 방은 신고/제재 가능 | 비즈니스용으로 만든 기능이라 안전 |

→ **결론: 처음엔 채널을 만들고, 사업자 등록 후 비즈니스 인증까지 받는 것이 정답.**
오픈채팅은 "무료 운세 공유방/대기방" 같은 커뮤니티 용도로 보조로 쓰면 좋습니다 (6장 참고).

## 1. 카카오톡 채널 개설 (10분)

1. PC에서 **카카오톡 채널 관리자센터** 접속 (`center-pf.kakao.com`, 또는 "카카오비즈니스" 검색) → 카카오 계정 로그인
2. **새 채널 만들기**
   - 채널 이름: 짧고 부르기 쉬운 이름 (예: "사주정원"처럼 4글자 내외). 이름은 나중에 바꾸기 번거로우니 신중히
   - 검색용 아이디: 영문, 인스타 아이디와 통일 추천
   - 카테고리: 생활서비스 > 운세/사주 계열
   - 소개글: "사주명리 1:1 상담 · 종합/궁합/재회 · 2시간 내 답변"
3. 프로필 사진: **얼굴이 보이는 캐릭터/인물 일러스트**(사례처럼 갓 쓴 선비 이미지)가 신뢰+기억에 유리
4. 배경 이미지: 사례의 음양오행·사주명리 동양화풍 배너처럼 톤을 통일
5. **채널 공개 ON, 검색 허용 ON**
6. **1:1 채팅 ON** (관리자센터 > 채팅 > 설정) — 이걸 켜야 고객이 메시지를 보낼 수 있고 "응답률"이 표시됩니다
7. 휴대폰에 **카카오톡 채널 관리자 앱** 설치 → 상담 알림 받기

## 2. 비즈니스 인증 (파란 체크) — 신뢰도 최대 무기

➡ 사업자등록 방법·업종코드·세금은 [`사업자등록_가이드.md`](./사업자등록_가이드.md) 참고

1. 사업자등록 먼저 (홈택스에서 온라인 신청, 무료, 보통 1~3일)
   - 업종코드 **930909** (점술 및 유사 서비스업), 간이과세자로 시작 가능
   - 간이과세자는 통신판매업 신고가 보통 면제
2. 관리자센터 > 관리 > **비즈니스 정보 → 비즈니스 인증 신청** → 사업자등록증 업로드
3. 심사 통과 시 파란 체크 + 검색 노출 강화, 단체 메시지 기능 등 사용 가능

## 3. 채팅 시작 인사말 & 자동응답 세팅 (핵심)

관리자센터 > **채팅 > 자동응답** 메뉴에서 설정합니다. (메뉴 명칭은 카카오 업데이트로 바뀔 수 있음)

1. **채팅 시작 인사말**: 처음 들어온 사람에게 자동 발송 → "안녕하세요. 무엇을 도와드릴까요?"
2. **키워드 자동응답** 만들기 — 키워드별로 이미지+텍스트(카드형) 메시지 1개씩:
   - `후기` / `이벤트 복비 안내` / `필독 사항` / `신청양식 및 계좌`
   - 동의어도 같이 등록: `복비`, `가격`, `얼마`, `계좌`, `신청`, `양식` 등
3. **상담 시간 외 자동응답**: "지금은 상담 시간이 아니에요. 신청양식 남겨주시면 순서대로 답변드립니다."
4. 복잡한 시나리오(버튼 → 다음 버튼 → 결제)가 필요하면 **카카오 i 오픈빌더(챗봇)** 로 확장 가능. 처음엔 기본 자동응답으로 충분합니다.

➡ 붙여넣기용 문구는 [`자동응답_문구.md`](./자동응답_문구.md)에 전부 준비해 두었습니다.

## 4. 채팅방 메뉴 (노란 버튼) 세팅

관리자센터 > **채팅 > 채팅방 메뉴**

사례와 같은 구성 (위 1칸 + 아래 3칸):

```
┌──────────────────────────────┐
│      소중한 내담자들의 후기      │  ← 가장 넓은 칸 = 신뢰부터
├─────────┬─────────┬──────────┤
│이벤트 복비│ 필독 사항│신청양식 및 계좌│
│  안내 (N)│         │          │
└─────────┴─────────┴──────────┘
```

- 각 버튼 동작 = **"메시지 보내기"** 로 설정하고, 보내는 문구를 3장에서 만든 자동응답 키워드와 **글자 하나까지 똑같이** 맞추기 → 버튼 누르면 고객이 키워드를 보낸 것처럼 되고 자동응답 카드가 바로 뜸
- `후기`는 "링크 열기"로 인스타 하이라이트/블로그 후기 모음에 연결해도 됨
- 새 이벤트 칸에 `N` 배지가 붙도록 업데이트할 때마다 메뉴를 갱신

**동선 설계 원칙: 후기(신뢰) → 가격(할인) → 필독(기대치 조율) → 양식+계좌(결제)**
고객이 사람과 대화하기 전에 스스로 결제까지 가도록 만드는 게 핵심입니다. 응답률이 76%여도 매출이 나는 이유.

## 5. 인스타그램 → 채널 연결 (유입)

1. 채널 **1:1 채팅 바로가기 링크** 복사: 관리자센터 > 채널 홈 > 채널 URL (`http://pf.kakao.com/_xxxxx`) 뒤에 `/chat` 을 붙이면 바로 채팅창이 열림
2. 인스타 프로필 링크에 위 링크 등록 (여러 링크면 링크트리류 사용)
3. 인스타 프로필 **"문의하기/예약하기" 버튼**에도 연결
4. 인스타 DM 자동응답: 게시물 댓글에 "사주" 남기면 DM으로 채널 링크 발송 (ManyChat 등 인스타 공식 파트너 자동화 툴)
5. 사례처럼 채팅창에 "이전 페이지: instagram" 이 찍히는 건 인스타에서 링크 타고 들어왔다는 표시 → 유입 경로 확인 가능

➡ 인스타 프로필/릴스/스토리 문구도 [`자동응답_문구.md`](./자동응답_문구.md)에 있습니다.

## 6. 오픈채팅을 보조로 쓰는 방법 (선택)

- 카카오톡 > 채팅 탭 > 오른쪽 위 말풍선+ > **오픈채팅** > 그룹채팅 만들기
- 용도: "오늘의 운세 무료 공유방", "이벤트 알림방" → 모인 사람에게 채널 링크 공지
- 주의: 오픈채팅은 영리 목적 광고·도배 시 신고되어 이용 제한될 수 있으니 **판매는 채널에서**, 오픈채팅은 무료 콘텐츠 위주로

## 7. 꿀팁 & 필살기

### 전환율 (보고 → 신청)
1. **가격표는 "정가(X) → 할인가(O)" 형식**: 사례처럼 50,000원(X) → 35,000원(O). 앵커 효과로 할인가가 싸게 느껴짐
   - ⚠ 한 번도 그 정가로 판 적 없는데 정가라고 표기하면 **표시광고법상 허위·과장 광고** 소지가 있습니다. 정가를 실제로 운영한 기간을 두세요.
2. **희소성은 진짜로**: "하루 3명 한정"은 실제로 지킬 수 있는 수로 설정. 매일 "1명 남았습니다"를 고정으로 쓰면 신고/신뢰 하락 리스크
3. **상품 구성 = 미끼 + 주력 + 고가**
   - 미끼: 1인 종합 35,000원 / 주력: 2인 궁합 50,000원 / 고가: 재회+궁합 80,000원
   - 재회·궁합(연애 고민)이 가장 절박하고 객단가가 높음 → 메뉴 상단에
   - 작명·택일은 "문의" 처리 → 고가 상담으로 연결
4. **신청양식에 "궁금한 점 혹은 고민"** 칸을 꼭 넣기 → 고객이 스스로 몰입, 상담 품질↑, 후기↑
5. **"출생시간 모르면 '모름'이라고 적어주세요"** 같은 친절한 문장 → 이탈 방지
6. 계좌는 **토스뱅크처럼 링크로 누르면 바로 송금되는 형식**이 편함. 예금주는 일부 가림 처리(이*돈)
7. 결제 흐름: 양식+입금 → "입금 확인되었습니다, ○시간 내 전달" 자동 문구 → 결과 전달 → 후기 요청

### 신뢰 (후기)
8. 후기는 **카톡 캡처(개인정보 모자이크)** 가 가장 강력. 후기 버튼을 메뉴 최상단 넓은 칸에
9. 상담 전달 24시간 후 "후기 남겨주시면 다음 상담 10% 할인" → 후기+재구매 동시에
10. 인증 배지(파란 체크)와 일관된 브랜드 이미지(동양화 배너, 선비 캐릭터)

### 운영 효율
11. 결과지는 **템플릿화**: 성격/재물운/연애운/직업운/올해·내년 흐름/조언 순서로 고정 → 1건당 작성시간 단축
12. 만세력 앱/사이트로 원국 추출 후 해석에 시간 집중
13. 응답률 표시가 신뢰에 영향 → 알림 켜고, 상담 가능 시간 명시
14. 고객을 **채널 친구**로 쌓아 두면 명절/신년운세 시즌에 단체 메시지로 재판매 (1월, 입춘, 추석이 성수기)

### 반드시 지킬 것
15. 소득 신고: 계좌이체 매출도 모두 소득. 사업자 등록 후 종합소득세 신고
16. 개인정보: 생년월일·이름·고민은 민감 정보 → 상담 후 보관 기간 정해서 삭제, 캡처 공개 시 모자이크
17. 환불 규정을 "필독 사항"에 명시 (결과 전달 전/후 환불 기준)
18. "반드시 된다/재회 100%" 같은 단정·보장 표현 금지
