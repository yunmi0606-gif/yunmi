# 사주 상담 사업자등록 가이드

> 2026년 9월 기준 정리입니다. 세법 기준금액·경비율은 매년 바뀔 수 있으니 신청 직전에 홈택스에서 한 번 더 확인하세요.

## 1. 자격 기준: 자격증 필요 없음

- 사주·점술업은 **허가·면허가 필요 없는 자유업**입니다. 역술 자격증(민간자격)이 없어도 등록 가능
- 만 19세 이상, 본인 명의 신분증이면 누구나 가능 (미성년자는 법정대리인 동의 필요)
- 직장인 부업도 등록 가능 → 단, **회사 취업규칙의 겸업 금지 조항**은 따로 확인
- 민간 "역학 자격증"은 신뢰 마케팅 용도일 뿐, 법적 요건 아님

## 2. 업종코드·카테고리 (가장 중요)

| 항목 | 입력값 |
|---|---|
| **업종코드** | **930909** |
| 업태 | 협회 및 단체, 수리 및 기타 개인 서비스업 |
| 종목 | 점술 및 유사 서비스업 |
| 표준산업분류 | 96992 (점술 및 유사 서비스업) |
| 포함 범위 | 점술, 관상, 점성술, 풍수, 토정비결, 작명·택일 상담 등 |
| 부가가치세 | **과세 업종** (면세 아님) |
| 단순경비율 | 61.5% (자가 61.2%) |
| 기준경비율 | 20.1% (자가 20.5%) |
| 간이과세 부가가치율 | 30% (그 밖의 서비스업) |

**추가 업종(부업종)으로 넣으면 좋은 경우**
- 사주 결과지 PDF·전자책·강의를 **파일 상품으로 판매** → 전자상거래 소매업(통신판매업) 계열 코드를 추가
- 부적·굿즈 등 **실물 판매** → 해당 소매업 코드 추가
- 처음엔 **930909 하나만** 등록하고, 필요할 때 홈택스에서 업종을 추가해도 됩니다 (정정신고, 무료)

## 3. 간이과세자 vs 일반과세자

| | 간이과세자 (추천) | 일반과세자 |
|---|---|---|
| 조건 | 연 매출 1억 400만원 미만 예상 | 그 이상 또는 본인 선택 |
| 부가세 | 매출 × 30% × 10% = **매출의 약 3%** | 매출의 10% − 매입세액 |
| 연 매출 4,800만원 미만 | 부가세 **납부 면제** | 해당 없음 |
| 신고 | 1년에 1번 (1월) | 1년에 2번 (1월, 7월) |
| 세금계산서 발행 | 원칙적으로 제한 | 가능 |

→ 개인 상담은 거의 기업 고객이 없으니 **간이과세자로 시작**하는 게 유리합니다.

## 4. 준비물

- 신분증
- 공동인증서(또는 간편인증: 카카오·네이버·토스 등) → 홈택스 로그인용
- **사업장 주소**: 온라인 상담이면 **자택 주소로 등록 가능**
  - 자가: 추가 서류 없음
  - 월세·전세: 임대차계약서 사본 (집주인 동의가 필요한 경우 있음. 계약서에 사업자 등록 금지 특약이 있는지 확인)
  - 자택 노출이 싫으면 비상주 사무실(공유오피스 주소 서비스, 월 1~3만원대) 이용
- 상호명 (예: "사주정원") — 개인사업자는 상호 중복 제한이 거의 없지만, **상표권**은 키프리스(kipris.or.kr)에서 한 번 검색해 보세요

## 5. 신청 방법 (홈택스, 온라인 15분)

1. **홈택스(hometax.go.kr)** 로그인
2. 메뉴: **신청/제출 → 사업자등록 신청·정정 등 → 개인 사업자등록 신청**
   (모바일 앱 "손택스"에서도 가능. 메뉴 이름은 개편에 따라 조금 다를 수 있음)
3. 입력
   - 상호명, 개업일자(실제 시작일 또는 예정일)
   - 사업장 주소 (자택 가능)
   - 업종 선택 → **업종코드 930909 검색** 후 등록
   - 과세유형: **간이과세자**
   - 사업장 구분: 자가/타가, 임대차 정보
   - 공동사업자: 없음
   - 사이버몰 정보: 인스타·카카오 채널 주소 입력 가능 (선택)
4. 서류 첨부 (임대차계약서 등) → 제출
5. **처리 기간: 보통 1~3일** (현장 확인이 필요하면 최대 1주 정도)
6. 승인되면 홈택스에서 **사업자등록증 PDF 발급** → 카카오 채널 비즈니스 인증에 사용

오프라인: 가까운 세무서 민원봉사실에서 신분증만 가지고 가도 당일 발급 가능

**기한:** 사업 시작일로부터 20일 이내 등록. 늦으면 미등록 가산세(매출의 1%)가 붙을 수 있습니다.

## 6. 통신판매업 신고, 해야 하나?

카톡·인스타로 상담을 판매하고 계좌이체로 받으면 **통신판매**에 해당할 수 있습니다.

- **신고 면제**: ① 직전 연도 통신판매 거래 횟수 50회 미만, 또는 ② **간이과세자**
- 즉, **간이과세자로 시작하면 보통 신고 면제**
- 일반과세자로 전환되거나 거래가 많아지면 → 정부24 또는 시·군·구청에서 신고 (구매안전서비스 확인증 필요. 계좌이체만 받는 경우 은행에서 발급 가능한지 확인)
- 규모가 커지면 신고해 두는 편이 안전합니다. 면제 기준은 바뀔 수 있으니 관할 구청 지역경제과에 한 번 문의하세요.

## 7. 등록 후 바로 할 일

1. **사업용 계좌 만들기**: 사업자등록증으로 은행에서 개설 → 홈택스에 "사업용 계좌 신고"(간편장부 대상자는 의무는 아니지만 강력 추천. 개인 돈과 섞이지 않게)
2. **카카오톡 채널 비즈니스 인증** 신청 (사업자등록증 업로드)
3. **현금영수증 가맹점 가입** 확인: 소비자 대상 업종이라 매출이 커지면 가입 의무가 생길 수 있음 → 홈택스에서 가입 가능, 고객 요청 시 발급
4. **홈택스에 사업용 신용카드 등록** → 경비 자동 집계
5. **간편장부**(엑셀이나 무료 장부 앱)로 매출·경비 기록: 신청 건별 입금일, 금액, 이름

## 8. 세금 일정 한눈에

| 시기 | 할 일 |
|---|---|
| 1월 25일까지 | 부가가치세 신고 (간이과세자는 연 1회) |
| 5월 31일까지 | 종합소득세 신고 (전년도 소득) |
| 7월 25일까지 | 일반과세자만 부가세 1기 확정신고 |

- 첫해·소규모는 **단순경비율(61.5%)** 로 신고 가능한 경우가 많음 → 매출 1,000만원이면 약 385만원만 소득으로 계산
- 부업이면 근로소득과 합산되어 세율이 올라갈 수 있으니 5월에 꼭 합산 신고
- 건강보험: 직장인 부업은 사업소득이 연 2,000만원을 넘으면 추가 보험료가 나올 수 있음. 지역가입자는 소득에 따라 보험료가 오를 수 있음

## 9. 자주 묻는 질문

**Q. 사업자 없이 먼저 해봐도 되나요?**
처음 몇 건 테스트는 가능하지만, 계속 반복해서 돈을 받으면 사업자입니다. 카카오 비즈니스 인증도 사업자등록증이 필요하니 빨리 등록하는 게 낫습니다. 사업자 없이 번 돈도 5월 종합소득세 신고 대상입니다.

**Q. 프리랜서(3.3%)로 하면 안 되나요?**
3.3%는 회사가 나에게 돈을 줄 때 떼는 방식입니다. 고객에게 직접 받는 1:1 상담은 사업자등록이 맞습니다. (사주 앱·플랫폼에 소속된 상담사로 활동하면 3.3% 방식일 수 있음)

**Q. 창업 세액감면 받을 수 있나요?**
청년창업 세액감면은 대상 업종이 정해져 있어 점술업은 해당되지 않을 가능성이 큽니다. 세무서에 확인하세요.

**Q. 세무사가 필요한가요?**
간이과세·단순경비율 단계는 홈택스로 혼자 충분히 가능합니다. 연 매출 수천만원 이상이 되면 세무사 기장(월 5~10만원대)을 고려하세요.
